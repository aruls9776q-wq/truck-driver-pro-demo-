TRUCK DRIVER PRO - ANDROID PROJECT

இந்த ZIP என்பது Android Studio / GitHub Actions மூலம் APK build செய்யும் source project. இது APK file அல்ல.

APK build (GitHub Actions):
1. ZIP-ஐ extract செய்து உள்ளே இருக்கும் TRUCK_DRIVER_PRO_ANDROID folder contents-ஐ GitHub repository-க்கு upload செய்யவும்.
2. GitHub repository-ல் Actions tab திறக்கவும்.
3. Build Truck Driver Pro APK workflow-ஐத் தேர்ந்தெடுத்து Run workflow அழுத்தவும்.
4. Build முடிந்ததும் Truck-Driver-Pro-debug-apk artifact-ஐ download செய்யவும்.
5. ZIP artifact-ஐ extract செய்து app-debug.apk-ஐ Android-ல் install செய்யவும்.

Local build: Android Studio, JDK 17, Android SDK Platform 35 மற்றும் Gradle 8.9 தேவை.

குறிப்பு: Login/register தற்போது HTML demo/local storage அடிப்படையிலானது; online account database/backend இல்லை.


DEMO BUILD FEATURES (OFFLINE):
- Local demo account registration and login
- Trip create, history, delete, KM and expense calculations
- Earnings summary and editable profile
- Logout and local session handling
- Data stored only on this device (clear app data to reset)
- No backend, OTP, GPS tracking, or real payment processing in this demo.
