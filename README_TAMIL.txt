TRUCK DRIVER PRO - VERSION 1.1 UPDATE

இந்த update-ல் சேர்க்கப்பட்டவை:
1. Driver Profile-ல் Camera / Gallery மூலம் புகைப்படம் தேர்வு செய்து இந்த போனில் சேமிக்கலாம்.
2. Start Duty / End Duty நிலை உள்ளூரில் சேமிக்கப்படும்.
3. Add Trip செய்ததும் Planned நிலை உருவாகும்.
4. Start Trip அழுத்தினால் Google Maps வழித்தடம் திறக்கும்.
5. On the way நிலையில் Reached Destination அழுத்தலாம்.
6. Ending KM கொடுத்து Complete Trip செய்யலாம்.
7. Completed Trip-இல் Add Next Trip வசதி கிடைக்கும்.

முக்கிய குறிப்புகள்:
- இது local/offline demo app. Trip, profile, photo ஆகியவை இந்த சாதனத்தின் WebView storage-ல் சேமிக்கப்படும்.
- Live GPS tracking, server sync, real driver monitoring இதில் இல்லை.
- Camera intent மூலம் கிடைக்கும் preview சில போன்களில் thumbnail அளவில் இருக்கலாம். Gallery-யில் முழு resolution photo தேர்வு செய்யலாம்.
- GitHub Actions மூலம் debug APK build செய்யவும்.
- ஒவ்வொரு GitHub Actions build-லும் debug signing key மாறக்கூடும்; புதிய APK நிறுவும்போது பழைய app uninstall செய்ய வேண்டியிருக்கலாம். Uninstall செய்தால் local app data அழியும்.
